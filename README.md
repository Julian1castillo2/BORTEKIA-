🏢 BORTEKIA
===========

Tecnología que impulsa tu negocio.

------------------------------------

📖 SOBRE EL PROYECTO
---------------------

BORTEKIA ayuda a pequeñas y medianas empresas a mantener su tecnología
organizada, segura y funcionando, mediante soporte TI, digitalización,
automatización y soluciones empresariales.

Este repositorio contiene la página web oficial de presentación de
servicios, construida con HTML, CSS y JavaScript puro, sin frameworks
ni dependencias externas.

------------------------------------

✨ CARACTERÍSTICAS
-------------------

🧭 Navbar responsive con menú hamburguesa en móvil
🖥️ Hero section con propuesta de valor y llamados a la acción
🗂️ Catálogo de 6 servicios con acordeones interactivos
🔄 Sección BORTEKIA CARE con 3 planes mensuales comparables
🪜 Escalera de ventas animada paso a paso
🎨 Paleta de marca visible (negro + amarillo + blanco)
📩 Formulario de contacto funcional
💬 Botón flotante de WhatsApp
🌀 Animaciones al hacer scroll, diseño 100% responsive
⚡ Sin librerías externas, carga instantánea

------------------------------------

📦 INSTALACIÓN
---------------

1. Clona el repositorio
2. Entra a la carpeta del proyecto
3. Abre el archivo index.html en tu navegador

No requiere instalación de dependencias ni servidor.

------------------------------------

🛠️ PERSONALIZACIÓN
--------------------

Todo el contenido dinámico (servicios, planes y escalera de ventas) se
genera desde arrays de JavaScript dentro de index.html:

  const services = [ ... ]     Catálogo de servicios
  const plans = [ ... ]        Planes de BORTEKIA CARE
  const ladderSteps = [ ... ]  Pasos de la escalera de ventas

Otros ajustes rápidos:
  - Colores: variables --black y --yellow en :root
  - WhatsApp: número dentro del botón flotante
  - Formulario: conectar a backend o servicio externo
